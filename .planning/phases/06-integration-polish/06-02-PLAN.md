# Plan 06-02: PWA Configuration and Final Polish

## Objective
Make the Next.js app installable as a PWA with a manifest.json, service worker, and generated icons, and prepare it for demo usage.

## Tasks

```xml
<task>
<id>06-02-01</id>
<title>Create Icon Generator Script</title>
<read_first>
- frontend/public/icon.png
</read_first>
<action>
1. Create `frontend/scripts/generate-icons.js`.
2. This script uses the `sharp` module to read `public/icon.png`. Use `require('sharp')` and `require('fs')`. Ensure `public/icons` directory exists.
3. It writes two files: 
   - `public/icons/icon-192.png` (192x192)
   - `public/icons/icon-512.png` (512x512)
4. Add a `"generate-icons": "node scripts/generate-icons.js"` script to `frontend/package.json`.
</action>
<acceptance_criteria>
- `frontend/scripts/generate-icons.js` contains `require('sharp')`
- `frontend/scripts/generate-icons.js` contains `public/icons/icon-192.png`
- `frontend/package.json` contains `"generate-icons"`
</acceptance_criteria>
</task>

   ```javascript

   ```tsx
   <script dangerouslySetInnerHTML={{ __html: `

       navigator.serviceWorker.register('/sw.js');
     }
   `}} />
   ```
