# Plan 02-01: FastAPI Server & OCR Integration

## Objective
Set up the FastAPI project structure and implement the Google Cloud Vision OCR integration for extracting and translating Mandarin characters from `multipart/form-data` image uploads. Returns grouped word/line bounding boxes.

- Create `backend/requirements.txt` containing `fastapi`, `uvicorn[standard]`, `python-multipart`, `google-cloud-vision`
- Create `backend/main.py` configuring the FastAPI app with CORS middleware
- Include basic placeholder `app.get("/")` for health check
</action>

- Structure the results into words/lines (as per D-02) returning a list of dicts with keys like `text` and `bounding_box` (with `x`, `y` vertices).
