# Plan 04-01: WhatsApp Webhook Setup & Rate Limiting

## Objective
Configure the FastAPI webhook for the Meta WhatsApp Cloud API to receive messages and handle token verification. Implement global rate limiting across the entire FastAPI app and a tailored limiter mechanism for the webhook.

## Context
- Webhook must respond to `GET` for hub verification, and `POST` for incoming messages.
- Must read configuration (app ID, phone number ID, bearer token) from env.
- Enforce strict API rate limiting, particularly securing the WhatsApp route per sender phone number from the payload to prevent API budget abuse.
