# Plan 04-02: Hybrid Conversation Engine

## Objective
Implement a Gemini Flash LLM intent parser to decode raw natural language strings from WhatsApp into strict structured intents. Execute backend rules based on the parsed ingredient intent, query the MongoDB knowledge base, and return rule-based safety responses or a predetermined fallback message for missing components.

## Context
- LLM is strictly single-turn stateless ping-pong.
- Unknown ingredients enforce a specific hardcoded message.
- Uses `google-generativeai`.
