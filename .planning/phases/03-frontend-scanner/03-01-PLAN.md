# Phase 03-01: Frontend Foundation & Design System

<objective>
Initialize the Next.js React PWA frontend and translate the Modern Apothecary Editorial design system (colors, typography, spacing) into strict Tailwind CSS configurations.
</objective>

<must_haves>
- Next.js project initialized with App Router.
- Tailwind CSS configured with the specific `primary` (#69000B), `primary_container` (#930014), `tertiary_container` (#CBA72F), and `surface` (#FFF8F7) colors.
- Custom fonts configured: Newsreader (Display/Headline), Inter (Body/Title), Noto Sans SC (CJK text).
- Base CSS resets and global glassmorphism utility classes.
- Basic `main` layout establishing the top-level container structure.
</must_haves>

<deep_work_rules>
- Every task MUST include `<read_first>`, `<action>`, and `<acceptance_criteria>`.
- The `<action>` MUST be highly explicit and concrete (e.g., exact hex codes, explicit font families).
- The `<acceptance_criteria>` MUST be mechanically verifiable (grep or CLI output).
</deep_work_rules>

  </read_first>
  <action>
